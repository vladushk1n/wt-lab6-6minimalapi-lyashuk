# Esport Tournament Manager API (Lab 6)

| Метод | URL | Назначение |
| :--- | :--- | :--- |
| GET | `/` | Проверить работу приложения |
| GET | `/api/info` | Получить информацию о приложении |
| GET | `/api/products` | Получить список игроков (поддерживает `?search=`) |
| GET | `/api/products/{id}` | Получить игрока по ID |
| POST | `/api/products` | Создать нового игрока |
| PUT | `/api/products/{id}` | Обновить данные игрока |
| DELETE | `/api/products/{id}` | Удалить игрока |
